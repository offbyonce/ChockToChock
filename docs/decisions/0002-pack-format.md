# 0002: Packs authored in YAML, read strictly, shipped as JSON

Date: 2026-11-08. Status: accepted.

## Context
Checklists run to hundreds of steps and need comments and per-step sources. YAML is
easier to write than JSON but has traps (silent typos, `NO` read as false).

## Decision
- Authors write YAML. `serde-saphyr` 2.1 reads it into the Rust types with unknown
  fields and duplicate keys rejected and strict booleans on. Errors give line and column.
- `pack.json` manifests stay JSON. JSON Schemas generated by `schemars` live in
  `schemas/` for editor autocomplete; a test fails if they drift.
- `pack check` enforces content rules: every step sourced, no blocked source domains,
  no images or PDFs, unique ids.
- Shared content will come from library packs and id-keyed overrides (Phase 1).

## Consequences
- Verified 2026-11-08: misspelled fields, duplicate keys and `NO` all behave correctly.
- `serde_yaml` (deprecated) and its forks are not used.
