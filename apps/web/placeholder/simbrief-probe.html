SimBrief probe

A test page for the Chock to Chock web beta. It checks that this site can load your latest SimBrief flight plan straight from your browser.

Your username goes directly from this browser to SimBrief. It is not stored, and nothing is sent to us.

Or load a saved plan file

No connection, or the button above fails? Save your plan from SimBrief as an XML or JSON file and choose it here. The file is read on this device only.

To save one: in your browser, open https://www.simbrief.com/api/xml.fetcher.php?username= followed by your username, then save the page as an .xml file.
