# Screenshot fixtures

`board-ofp.json` is an invented SimBrief OFP reply (KSEA to KSFO) with the values the batch 4 boards
show, so the review screenshots can put the Flight pages in the boards' state through the app's own
"Drop a saved OFP file here". It has no crew, user or account fields at all.
